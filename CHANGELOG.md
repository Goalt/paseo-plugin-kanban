# CHANGELOG

Плагин `kanban-board` для Paseo 0.6.1. Версии соответствуют спринтам из `docs/SPEC.md` §8.

## 0.3.0 — Спринт 3: полировка и релиз (2026-09-07)

- Фильтр по сессии в шапке доски (выпадашка «Все сессии» / конкретная сессия), метки
  сессий на карточках и в модалке.
- Зависимости тикета в модалке: подписи по направлению связи
  (`заблокирован` / `блокирует` / `связан с`), «заблокирован» — цветом `statusDanger`,
  переход по связи в модалку связанного тикета.
- Счётчик «в работе N» в шапке доски. Бейджа у пунктов сайдбара и панелей в 0.6.1 нет —
  клиент демона пересобирает вклад сайдбара из четырёх полей.
- Выбранный проект переживает перемонтирование поверхности и `paseo plugin reload`:
  RPC `kanban.state.get/set`, память процесса + файл (`KANBAN_STATE_FILE`).
- Полировка обеих тем и узкой панели воркспейса: в компактном режиме шапка
  раскладывается в две строки, чип сессии сужается.
- README и CHANGELOG.

## 0.2.0 — Спринт 2: управление тикетами (2026-09-06/07)

- Модалка деталей тикета: описание, колонка, сессия, вложения, время обновления.
- Перемещение: кнопки ◀ ▶ на карточке (соседние колонки) и выбор колонки в модалке.
- Полный CRUD: создание из колонки («+», форма title/description/priority),
  редактирование в модалке, удаление с подтверждением (сабтаски удаляются каскадом —
  сверено с реальной схемой БД).
- Сабтаски: список с чекбоксами, завершение (перенос в Done — семантика
  `complete_subtask`), создание из модалки.
- Общий раннер мутаций: одна мутация за раз (двойной клик не двигает тикет дважды),
  ошибки — тостом, после любой мутации доска сразу перезабирает снапшот.
- RPC: `kanban.ticket`, `kanban.ticket.move/create/update/delete`,
  `kanban.subtask.create/complete`. Имена RPC — только нижний регистр: демон
  отвергает camelCase.
- `dev/rpc-smoke.mjs --mutations` — полный CRUD-цикл в изолированном проекте
  `plugin-sandbox`.

## 0.1.0 — Спринт 1: каркас и чтение (2026-09-06)

- Каркас плагина: `index.ts`, точки входа (сайдбар, панель воркспейса/эксплорера,
  Command Center), типы SDK 0.6.1.
- RPC-контракт на zod: `kanban.snapshot`, `kanban.version`, `kanban.projects`.
- HTTP-слой к REST mcp-kanban: `KANBAN_URL`, таймауты, нормализация ошибок, сборка
  снапшота, подсчёт прогресса сабтасков на сервере плагина.
- WS-версионирование доски: подписка на `/ws`, `version++` на события, реконнект с
  бэкоффом (починено: Node 22 при неудачном connect шлёт только `error`, без `close`).
- Автостарт борды через `docker exec`, если `/api/health` молчит.
- UI доски: колонки лентой, карточки с приоритетом, сессией и прогрессом; переключатель
  проектов; live-поллинг версии раз в 2 с; empty-states и экран ошибки с Retry.
- `dev/rpc-smoke.mjs` и `dev/render-test.mjs` — смоук серверных RPC и рендер клиента.
